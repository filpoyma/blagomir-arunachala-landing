# Заявки с сайта в Telegram

Форма на сайте отправляет `POST /api/bookings`. Сервер формирует текст заявки и шлёт его в личные сообщения от бота каждому получателю из `TELEGRAM_CHAT_IDS`.

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Команда `/newbot`, задайте имя и username (например `@arunachala_booking_bot`).
3. Скопируйте **token** — это `TELEGRAM_BOT_TOKEN`.

## 2. Получатели заявок

Каждый человек, который должен получать заявки:

1. Открывает вашего бота в Telegram.
2. Нажимает **Start** или отправляет `/start`.

Без этого бот не сможет писать в личку.

## 3. Узнать chat_id

После `/start` от каждого получателя откройте в браузере (подставьте token):

```
https://api.telegram.org/bot<TOKEN>/getUpdates
```

В ответе найдите `"chat":{"id":123456789,...}` — это chat_id. Для лички с ботом id обычно положительный.

Несколько получателей — несколько id через запятую:

```
TELEGRAM_CHAT_IDS=111111111,222222222
```

## 4. Локальная разработка

Скопируйте `.env.example` в `.env.local` и заполните переменные. Перезапустите `pnpm dev`.

## 5. Продакшен (Vercel и др.)

В настройках проекта добавьте те же переменные окружения **без** префикса `NEXT_PUBLIC_`:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_IDS`

После деплоя отправьте тестовую заявку с сайта и проверьте, что все id из списка получили сообщение.

## Безопасность

- Token бота не должен попадать в репозиторий и во фронтенд.
- Поле `website` в форме — honeypot; заполненное ботами заявки отклоняются без отправки в Telegram.
